# Deterministic CPU demonstration — 2026-09-19

This is a compact, committed summary of the measured demonstration generated by:

```bash
contextlab benchmark run --config configs/benchmark.yaml
contextlab benchmark report --results results/context-policy-demo
```

The run exercised four policies at short, medium, and long budgets against clean
copies of the same `localized-divide-zero` baseline. All 12 official evaluations
passed, all runs made four repository tool calls, one baseline SHA was used, and
seven charts were generated. Automatic retrieval recovered 752 tokens per
retrieval-policy run.

| Policy | Conditions | Official success | Median total tokens per condition |
|---|---:|---:|---:|
| full-history | 3 | 3/3 | 1651 |
| bounded-tool-output | 3 | 3/3 | 1651 |
| retrieval | 3 | 3/3 | 3447 |
| compaction | 3 | 3/3 | 1651 |

This is a deterministic scripted-model integration demonstration, **not evidence
about real model quality or policy superiority**. Each condition has `n=1`, the
task is small, and compaction thresholds were not reached. The retrieval token
difference confirms accounting and recovery paths, not a general cost claim.

Raw run JSONL, generated patches, and PNG charts are intentionally ignored by
Git because they are reproducible runtime artifacts. The full local report is
written to `results/context-policy-demo/report.md`; the committed
`summary.json` and `aggregate.csv` provide machine-readable provenance.

Environment: Python 3.12.7 on macOS arm64. Docker Desktop 4.63.0 / Engine 29.2.1
was available. No NVIDIA GPU or live vLLM endpoint was available, so no real
inference experiment was executed.
