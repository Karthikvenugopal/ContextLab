# ContextLab

ContextLab is a research-oriented framework for measuring how context-management
policies affect autonomous coding agents. It compares full-history retention,
bounded tool output, retrieval-based recovery, and context compaction under a
shared agent, inference backend, tool set, and evaluation protocol.

> Development is in progress. The repository is being built as an executable,
> CPU-testable vertical slice with optional vLLM-backed experiments.
